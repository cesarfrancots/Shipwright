# Test: divergent ideation

## Input

Use the `ideation-engine` skill.

Brainstorm ideas for helping remote team managers spot burnout earlier in a collaboration product.

## Expected Behavior

- [ ] Output defaults to divergent mode.
- [ ] Output includes exactly 10 ideas.
- [ ] Output includes explicit RICE dimensions and a ranked table.
- [ ] Output avoids near-duplicate ideas by collapsing obvious duplicates into one core concept with variants.
- [ ] Output breaks near-ties deterministically instead of pretending to have extra precision.
- [ ] Output recommends top ideas instead of ending at raw brainstorming.
