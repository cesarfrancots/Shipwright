# Diagram Types

## Flowchart

Use for decision flows, onboarding paths, and operations with branching logic.

## Sequence

Use for time-ordered interactions across users, services, and systems.

## State

Use for lifecycle transitions such as draft, approved, paused, archived.

## User Journey

Use for end-to-end customer experience stages and emotional or friction annotations.

## Architecture

Use for systems, services, data stores, and integration boundaries.

## Entity Relationship

Use for core objects and their relationships in a domain model.
