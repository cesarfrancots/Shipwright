# Competitive Intel

## When to Use This Skill

Use this skill when the user needs a quick or deep competitor assessment for a product, market, or feature area.

Read `references/swot-template.md` before drafting.

If the user does not specify quick or deep mode, default to quick.

## Instructions

1. Identify the product, competitors, and comparison dimensions.
2. Choose quick or deep mode based on the request and tool availability.
3. If live research is unavailable, state the limitation clearly.
4. Compare competitors on capabilities, positioning, strengths, weaknesses, and likely tradeoffs.
5. End with gap analysis and recommended positioning.
