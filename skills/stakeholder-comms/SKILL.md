# Stakeholder Comms

## When to Use This Skill

Use this skill when the user has raw status notes, launch details, or sprint outcomes that need rewriting for a specific audience.

Read `references/audience-profiles.md` before drafting.

If the audience is not specified, ask the user: "Which audience should this update target?"

## Instructions

1. Identify the audience and delivery format.
2. Preserve factual content while adjusting emphasis, tone, and terminology.
3. Highlight business impact for executives, technical detail for engineering, and customer effect for customer-facing audiences.
4. Keep updates skimmable.
5. If generating multiple variants, reuse the same factual core and change only what the audience needs.

## Output Format

- Audience:
- Purpose:
- Key message:
- Draft:
- Risks or follow-ups:
