# Workflow Example: Feature Launch

## Goal

Prepare the measurement, market framing, and communication plan for launch.

## Flow

1. Run `metrics-definer` on the feature.
2. Run `competitive-intel` for positioning.
3. Run `stakeholder-comms` for internal and external launch messaging.

## Sample Prompt

```text
Define launch metrics for shared dashboard views, compare us to the main competitors, and draft an internal launch note plus customer release notes.
```

## Output Artifacts

- metric framework
- instrumentation plan
- competitor matrix
- launch communications
