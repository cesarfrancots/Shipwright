# Workflow Example: Idea to Spec

## Goal

Go from a loose opportunity to a reviewable specification.

## Flow

1. Run `ideation-engine` on the opportunity.
2. Select one idea and request a deep dive.
3. Run `prd-builder` on the selected concept.
4. Use `spec-diagrams` to add a user flow or sequence diagram to the spec.

## Sample Prompt

```text
Brainstorm ways to help sales managers prepare for customer calls, deep-dive the best idea, then draft a PRD and a user-flow diagram for it.
```

## Output Artifacts

- ranked idea list
- deep-dive concept notes
- PRD draft
- Mermaid diagram
